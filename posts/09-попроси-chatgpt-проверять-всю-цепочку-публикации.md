# Попроси ChatGPT проверять всю цепочку публикации

Автоматическая сборка полезна только тогда, когда ошибки действительно обнаруживаются.

## Запрос

> После каждого изменения:
>
> 1. проверь изменённые файлы;
> 2. запусти GitHub Actions;
> 3. дождись завершения build;
> 4. проверь artifact;
> 5. дождись deploy;
> 6. открой опубликованный сайт;
> 7. проверь, что новый пост реально присутствует;
> 8. только после этого сообщи результат.
>
> Если какой-либо этап завершился ошибкой, сначала найди причину и исправь её. Не объявляй работу завершённой по одному факту успешного commit.

Критерий готовности должен проверять путь: Markdown → подготовка поста → Jekyll → artifact → Pages deployment → опубликованный HTML.
