# Сделай заголовок из имени файла

После отказа от front matter остаётся вопрос: откуда взять заголовок.

## Запрос

> При сборке бери заголовок каждого поста из имени его Markdown-файла без расширения \`.md\`.
>
> Например, файл \`Как настроить GitHub.md\` должен получить title \`Как настроить GitHub\`.
>
> Не добавляй этот title в исходный Markdown.
>
> Сохраняй имя файла единственным источником названия поста.

Автор теперь работает только с именем файла и содержимым Markdown. Метаданные генерируются автоматически перед сборкой.
