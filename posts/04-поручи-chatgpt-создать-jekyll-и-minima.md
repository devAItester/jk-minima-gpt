# Поручи ChatGPT создать Jekyll и Minima

Теперь можно поручить непосредственно создание сайта.

## Запрос

> Создай в репозитории минимальный сайт на Jekyll с темой Minima.
>
> Используй текущую рекомендуемую схему GitHub Pages через GitHub Actions.
>
> Создай только необходимые файлы.
>
> После создания проверь конфигурацию и сборку. Если сборка не проходит, исправь причину, а не скрывай ошибку.
>
> Пока сайт не собирается успешно, не переходи к отчёту о готовности.

Не нужно заранее диктовать содержимое каждого файла. В этом шаге проверяется способность ChatGPT самостоятельно собрать минимальное решение из требований.
