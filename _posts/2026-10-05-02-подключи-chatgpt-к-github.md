Теперь нужно дать веб-чату возможность работать с репозиторием, а не только рассказывать, что делать.

## Что сделать

В ChatGPT открой настройки подключений и подключи GitHub. Авторизуй доступ к нужному аккаунту и репозиториям.

После этого напиши:

> GitHub подключён. Используй подключённый GitHub для работы непосредственно с репозиторием. Не ограничивайся инструкциями: когда у тебя есть необходимые права, создавай и изменяй файлы сам.

## Проверка

Сначала попроси:

> Проверь, что ты действительно видишь мой репозиторий, его ветку по умолчанию и содержимое. Пока ничего не меняй.

Это отделяет реальный доступ к репозиторию от обычного знания ChatGPT о GitHub.
